# FullStack journey

A learning project (Node.js + Express).

## Notes rule

Whenever you change something in this folder (code, config, scripts, installed packages), add an entry to `notes.md` in the same turn:

- Keep it short: crucial info only, one line per bullet, no long explanations.
- Group by topic (`## Setup`, `## server.js`, `## app.js`, …). Add to the matching section or create a new one.
- Don't log answers that changed no files.
